# Monetra

Monetra is a simple banking system project built for practicing full-stack development using Spring Boot and React.

The goal of this project is to learn and improve skills in:

- Spring Boot backend development
- REST API creation
- Authentication and authorization
- Database integration
- Frontend and backend communication
- Modern React development

This repository contains the frontend application for the Monetra practice project.

## Tech Stack

### Frontend
- React
- TypeScript
- React Router
- Tailwind CSS
- shadcn/ui
- TanStack Query

### Backend (separate project repo)
- Spring Boot
- Spring Security
- PostgreSQL
- JPA / Hibernate

## Features
- User authentication
- Dashboard UI
- Banking-inspired interface
- API integration with Spring Boot backend
- Responsive design

## Purpose
This project is mainly for educational and practice purposes.  
It is not intended for production use or real financial transactions.

## Status
Currently under development.
